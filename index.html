Core Capabilities

One layer. Every provider.

Teresa abstracts complexity across the AI trading stack — so you focus on strategy, not plumbing.

Unified Routing

A single interface to route requests across OpenAI, Anthropic, Gemini, and any AI model — with automatic failover and load balancing.

teresa.route(task, providers)

Governance Layer

Define rules, policies, and access controls across all AI agents. Enforce compliance, rate limits, and spend caps per model or per strategy.

teresa.govern(policy, scope)

Full Control

Real-time observability, audit logs, kill switches, and fine-grained permissions over every AI-driven trade decision.

teresa.control(agent, override)

Robinhood Native

Deep integration with Robinhood's execution layer. Route AI-generated signals directly to Robinhood Chain for on-chain settlement.

teresa.execute(signal, robinhood)

Real-Time Analytics

Monitor every AI decision, track latency per provider, compare alpha generation across models with live dashboards.

teresa.observe(stream, metrics)

Fully open source. Fork it, extend it, contribute to it. The AI trading infrastructure that belongs to the community.

Architecture

How Teresa works

1

Define Your Strategy

Write your trading logic once using Teresa's unified SDK. No need to handle provider-specific APIs or authentication.

import { Teresa } from 'teresa-sdk';

const agent = new Teresa.Agent({
  strategy: 'momentum',
  providers: ['openai', 'anthropic'],
  execution: 'robinhood',
});
2

Apply Governance Policies

Set risk parameters, spend limits, and compliance rules. Teresa enforces them across every AI call automatically.

agent.govern({
  maxSpend: 500,
  allowedTickers: ['AAPL', 'NVDA'],
  riskProfile: 'conservative',
  auditLog: true,
});
3

Route & Execute

Teresa routes your AI signal to the optimal provider, then executes via Robinhood with full audit trail and real-time monitoring.

const signal = await agent.analyze(marketData);

// Auto-routes to best AI provider
// Validates against governance rules
// Executes on Robinhood if approved
await agent.execute(signal);

Open Source First.

Teresa is built in the open. Inspect the code, audit the routing logic, submit PRs, or fork it for your own AI trading stack. The infrastructure for AI trading should belong to everyone.
